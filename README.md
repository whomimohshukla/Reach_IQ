# Reach_IQ

A comprehensive lead management and customer engagement platform built with Next.js and modern web technologies.

## Project Structure

```
Reach_IQ/
├── Client/          # Next.js frontend application
└── Server/          # Backend API (coming soon)
```

## Features

- 🎯 Lead Management Dashboard
- 💬 Conversation Tracking
- 📊 Analytics & Insights
- 🤖 AI-Powered Interactions
- 📅 Booking Management
- 🔔 Follow-up Reminders
- 💬 WhatsApp Integration

## Getting Started

### Client Setup

```bash
cd Client
npm install
npm run dev
```

The application will be available at `http://localhost:3000`

## Tech Stack

- **Frontend**: Next.js 15, React 19, TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: Radix UI
- **State Management**: React Hooks

## Development

This project uses a monorepo structure with separate Client and Server directories.
